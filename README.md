# 自动异议 Edge 浏览器扩展

在网页点击时显示《逆转裁判》风格的异议特效，也可以将检测到的广告替换为提示内容或图片。

## 使用方式

1. 打开 Edge 的 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选择本仓库目录。
4. 在扩展弹窗中选择气泡样式、大小和功能开关。

“异议所有网页”和“异议所有广告”不能同时启用。设置页中的“异议特效音量”支持 0-100 调节，设为 0 即静音，图像特效仍会显示。

## 高级设置

- **自定义特效**：上传图像和音频，保存后即可选择使用。
- **广告拦截**：支持占位符、直接删除和图片替换，也支持加载时或点击时处理。
- **自定义过滤规则**：支持常用的 AdGuard URL 规则、元素隐藏规则和例外规则，可导入或导出 `.txt` 文件。

## 资源说明

扩展默认包含的图片和音频资源仅用于本地开发和扩展运行。
